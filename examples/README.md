# Examples

Public documents with clear terms, already present on the build machine (nothing was downloaded), plus the planted evaluation set and committed offline results.

## Demo pair: GPL-2.0 vs GPL-3.0 (`gpl/`)

| File | Source | SHA-256 |
|---|---|---|
| `GPL-2.0.txt` | `share/licenses/xz/COPYING.GPLv2` of a Git for Windows installation | `8177f97513213526df2cf6184d8ff986c675afb514d4e68a404010521b880643` |
| `GPL-3.0.txt` | `share/licenses/xz/COPYING.GPLv3` of the same installation | `3972dc9744f6499f0f9b2dbf76696f2ae7ad8af9b23dde66d6af86c9dfb36986` |

Both are unmodified. Verbatim copying is permitted by the texts themselves (see `../NOTICE.md`). Version 3 is a near-complete rewrite of version 2 (59 vs 122 paragraphs after ingest), which makes it a hard alignment case and a realistic long-document diff.

## Planted evaluation set (`planted/`)

| File | What it is |
|---|---|
| `cc-by-4.0.txt` | CC BY 4.0 legal code, unmodified: the `LICENSE` file of the `caniuse-lite` npm package (version 1.0.30001793). SHA-256 `fd3a263fe19ed8faa9068b43abaebafc02c77897b0c6fc09abc04bb592e5f16e`. The text is dedicated to the public domain under CC0 (stated at its end). |
| `cc-by-4.0-planted.txt` | The same text with planted changes, generated by `scripts/make_planted.py`. SHA-256 `c6e691013a779cee21fe6abc10ab5a609e3a4902d820ed36ff669398d5da5b18`. Not a license; a banner at the top says so. |
| `ground_truth.json` | One item per planted change, generated by the same script from the same edit list. |

The planted changes:

| Id | Category | Modes | Change |
|---|---|---|---|
| P01 | changed_value | diff | Cure period for reinstatement 30 -> 60 days |
| P02 | changed_permission | diff | "You may not offer or impose" -> "You may offer or impose" |
| P03 | removed_clause | diff, audit | Section 3(a)(3) deleted, list jumps from 2 to 4 |
| P04 | added_obligation | diff | New Section 3(a)(5): written notice 10 days before commercial sharing |
| P05 | changed_grant | diff | "irrevocable" -> "revocable" license |
| P06 | changed_party | diff | Licensor and licensee swapped in Section 7(a) |
| P07 | broken_reference | diff, audit | "Section 6(a)" -> "Section 9(a)", which does not exist |
| P08 | changed_definition | diff | Definition of Adapted Material narrowed |
| P09 | weakened_obligation | diff | "must comply" -> "should comply" |
| P10 | changed_value | diff | Section 6 dropped from the survival list |
| P11 | contradiction | diff, audit | Term set to five years, contradicting Section 6(a) |
| P12 | moved_clause | diff | Section 8(d) moved to Section 7(c) |
| P13 | undefined_term | diff, audit | "Licensed Rights" -> "Granted Rights" (never defined) |
| E01 | spelling_variant | diff | "licensed / License" -> "licenced / Licence" (editorial) |
| E02 | rewrap | diff | Paragraph re-wrapped (whitespace only) |
| E03 | typography | diff | Straight -> typographic quotes |
| E04 | punctuation | diff | Serial comma removed |
| E05 | hyphenation | diff | Line-break hyphen inside a word |
| X00 | fixture_banner | diff | Banner added (expected, not scored) |

`P*` items are substantive and must be found. `E*` items are editorial: a finding of severity minor or higher that cites only an `E*` paragraph counts against precision. Diff mode compares `cc-by-4.0.txt` (A) with `cc-by-4.0-planted.txt` (B); audit mode audits the planted copy alone against the four items marked `audit`. Anchors are verbatim snippets resolved to paragraph ids at scoring time; audit items also list the finding kinds that count (`audit_kinds`).

## Committed results (`results/`)

Everything here is offline and reproducible with `python scripts/reproduce_results.py` (a test checks it):

- `*/score-baseline.json`: the deterministic no-LLM baseline, scored against the ground truth.
- `*/report.md`, `*/report.json`, `*/score-fixture.json`: **fixture runs** with the scripted FakeLLM backend. They show every pipeline stage working on real text. Their findings are heuristic placeholders, and the fixture scores are circular (the fake and the planted set have the same author); they are not model results.

Real model runs are pending and will be added as separate directories.
